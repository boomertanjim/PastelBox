# PastelBox
PastelBox is a lightweight, web-based jukebox that plays requested songs.

## Description
PastelBox is more like a small desktop music application than a traditional web audio player. It features a custom pastel like interface, dynamic song metadata, playlist searching, queue management and smooth playback controls

The program currently has 12 songs loaded. Future Updates will add the feature to add custom tracks.

Songs are loaded from the music directory and their metadata is extracted using JS media tags. Each Playlist song has their own card having the title, artist name and cover photo.

Search Bar works on both the song title and artist name for easy access.

PastelBox uses mp3 metadata to show cover art in the vinyl in the middle. The vinyl spins infinitely for cool effect.

### Important
After opening the website, please wait for 2-3 minutes for all the songs to load.

## Features

- Play/Pause Controls
- Next-Track switching
- Playback Progress bar
- Playlist search capabilities
- Looping single songs
- Automatic play on next queue
- Delete button on each queued song

- The queue currently supports:
    - Adding songs
    - Preventing duplicate songs
    - Removing songs
    - Automatically advancing to next song
    - Removing currently playing song
    - Automatically starting next queued song
